# Look C, Cut-Out Council — corrections (binding; beat direction.md)

From two judges + lead. Short talk. Exact values exact.

1. **Sizes.** Use `docs/direction/study-content.json` for stage, ring, table, heads, bubbles. Ignore direction.md's radius/stage-height rule (defined in terms of each other) and its 200 px bubble floor.
2. **Page = white `#FFFFFF`** (old chalk `#F1F2EE` read as the starting cream). Dark page stays `#151B18`. Recompute every pair against white. Surface may need a very light step so cards still read; your call, report value.
3. **One typeface: Archivo only.** Drop Literata. Answer text = Archivo 16/26. Width axis (62–125) is the type identity: names fitted to heads by width, not shrunk.
4. **Top bar:** write short names beside the small figures (coloured dots alone = colour only signal). Or drop mini figures and write names.
5. **Status pill:** gaps between parts, no pipes, no dots. `Round 2   3:10 left   2 of 5 agree`.
6. **Bubbles:** no shadow. Edge in `line` token (3:1 or better), not the 1.29:1 hairline. Three corner sizes at most in whole study.
7. **Postures:** keep only the speaking lean. Remove "addressing" head turn and "reading" head drop (engine has not promised those signals).
8. **One staged moment only:** the fold at agreement. Start of debate = plain fade. (Study shows neither; note only.)
9. **Speaker ring** is same colour as head → weak. Check in panels 1 and 3. If speaker does not stand out at a glance: use ink ring with page-colour gap. Say which in `critique.md`.
10. **Keyboard focus on a seat** = ink rounded rectangle round whole figure. Ring round head = speaking only.
11. **Vote marks:** check = solid ink disc, page-colour check. Cross = page-filled disc, ink outline, ink cross, 2 px gap. Never red.
12. **Chat View values** (not in study): back to PDF's `#111111` on `#FFFFFF`, `#F2F2F2` on `#0E0E0E`. No hairline column separators. Note only.
13. **Table cloth** `#DEE5DD`: keep pale, do NOT deepen (green half-round table = card table). Not an identity colour; the 3:1 edge line is what the eye sees.
14. **Name fitting** must be measured in the browser (your widths were estimates). Consider one name size per council so heads look even. Light theme: watch indigo and claret (near-black) at small sizes. Dark theme: watch teal and ochre shouting.
15. **Figure must not look like the stock user icon.** Game-piece proportions: large head, narrow shoulders, name filling the head. This is the whole look.
16. Kept on purpose: no accent hue, ink controls, seven seats the only colour, one cut per seat body, pips meter with mark at number needed (may instead count with small figures; your call, report).
